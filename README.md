# 아침 두뇌 챌린지

학급용 Firebase + GitHub Pages 앱입니다. 로그인·포인트 상점·선생님 창의력 문제에 13개 두뇌 게임을 추가합니다.

직감(그림두더지·가운데만 봐·최고 숫자), 기억(순간기억·순서기억), 분석(블록매치·저울비교·사다리 연결), 계산(더쎈 망치·숫자풍선), 지각(조각퍼즐·선로잇기·시점추측)의 5영역을 하루 한 번 연속 진행합니다.

매일 06:00(한국 시각)에 갱신·정산합니다. 참여 보상 50P + 순위 보너스, 연습은 영역별 첫 완료 10P로 하루 최대 50P입니다. 게임 점수와 포인트는 별개입니다.

**Firebase 서버와 규칙을 먼저 배포해야 합니다. [배포 절차](DEPLOYMENT.md)를 확인하세요.** `npm test`, `npm run check`로 핵심 로직을 검증합니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. GitHub 저장소의 `Settings` → `Pages`로 이동합니다.
3. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
4. Branch를 `main`, 폴더를 `/root`로 선택한 뒤 저장합니다.

## 제공 기능

- 학생 로그인
- 매일 문제 공개
- 13게임 자동 출제와 하루 한 번 5영역 챌린지
- 오전 6시 순위 확정 및 중복 없는 보상 지급
- 누적 포인트 순위표
- 선생님 상품 등록
- 서버 검증 포인트 상점 구매
