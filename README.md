# 아침 두뇌 챌린지

27명 학급을 위한 Firebase Spark + GitHub Pages 앱입니다. 기존 로그인·상점·선생님 창의력 문제와 함께 13개 두뇌 게임을 제공합니다.

- 직감·기억·분석·계산·지각의 5영역을 각 60초씩 하루 한 번 도전합니다.
- 한국 시각 오전 6시에 새 도전이 열립니다. 완료한 도전은 마감 이후 본인이 접속할 때 50P를 지급합니다.
- 연습은 당일 도전 완료 후 열리며, 영역별 첫 완료 10P로 하루 최대 50P입니다.
- 순위는 기록 비교용이며 순위 보너스는 없습니다.
- 최근 7회 영역별 평균, 게임별 최고 기록, 재접속 이어하기를 제공합니다.

Cloud Functions나 유료 요금제를 사용하지 않습니다. 게임 점수는 브라우저에서 계산하고 포인트 한도·중복 지급·구매 가격은 Realtime Database 규칙으로 검사합니다. 학급 내부의 신뢰를 전제로 하며 자동 풀이를 막는 시스템은 아닙니다.
