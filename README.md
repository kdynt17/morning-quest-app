# 아침 두뇌 체조

27명 학급을 위한 Firebase Spark + GitHub Pages 앱입니다. 기존 로그인·상점·선생님 창의력 문제와 함께 13개 두뇌 게임을 제공합니다.

- 직감·기억·분석·계산·지각의 5영역을 각 60초씩 하루 한 번 도전합니다.
- 한국 시각 오전 6시에 새 도전이 열립니다. 완료한 도전은 마감 이후 본인이 접속할 때 50P를 지급합니다.
- 연습은 당일 도전 완료 후 열리며, 영역별 첫 완료 10P로 하루 최대 50P입니다.
- 순위는 기록 비교용이며 순위 보너스는 없습니다.
- 최근 7회 영역별 평균, 게임별 최고 기록, 재접속 이어하기를 제공합니다.

Cloud Functions나 유료 요금제를 사용하지 않습니다. 게임 점수는 브라우저에서 계산하고 포인트 한도·중복 지급·구매 가격은 Realtime Database 규칙으로 검사합니다. 학급 내부의 신뢰를 전제로 하며 자동 풀이를 막는 시스템은 아닙니다.

[배포 및 검증 안내](DEPLOYMENT.md)를 참고하세요.

## 디자인과 그림

- DS 『말랑말랑 두뇌교실』 결과 화면 느낌(크림 종이, 노란 제목 띠, 카키 보드, 돌판 라벨)으로 꾸몄습니다.
- 그림은 Higgsfield로 **한 번만** 만든 평면 2D 그림 26장(`assets/`, 약 240KB)을 계속 재사용합니다. 사이트가 돌아갈 때 AI·외부 서버를 쓰지 않습니다.
  - 박사 마스코트 6가지 표정, 5영역 아이콘, 그림두더지 동물 12장, 앱 아이콘
  - 원본 주소는 `assets/sources.txt`에 있고, 이 파일을 바꾸면 `Sync image assets` 워크플로가 내려받아 저장소에 커밋합니다.
- 사다리·선로·저울·블록·3D 탑·풍선 같은 게임 판은 그림 없이 `game-art.js`가 SVG로 그립니다. 문제는 `functions/domain.mjs`가 날짜를 씨앗으로 자동 생성하므로 그림을 더 만들 필요가 없습니다.

## 말랑그램(두뇌 무게)

- 영역 능력치(0~100) = 그 영역 60초 점수 ÷ 기준 점수(`brain-score.js`의 `AREA_REFERENCE`).
- 말랑그램 = 400g + 다섯 영역 능력치 합 × 3.2 → 400~2000g. 등급: 새싹·말랑·탱글·반짝·천재·전설의 두뇌.
- 하루 도전 결과 화면은 그날 5과목 점수로, 홈의 "나의 두뇌 무게"는 영역별 최근 7회 평균으로 계산합니다.
- 학생 기록이 쌓이면 `AREA_REFERENCE`만 조정하면 됩니다.

## 가입 승인·로그인

- 새로 가입한 학생은 `status: "pending"`으로 시작하고, 선생님이 `developer/`(관리 → 가입 승인 · 학생 관리)에서 승인해야 게임·지갑·순위를 쓰고 볼 수 있습니다. 기존 학생(status 없음)은 그대로입니다.
- 로그인 정보는 브라우저에 저장돼 다시 열면 바로 들어갑니다. 로그인 화면에 "로그인 상태 유지"와 "비밀번호를 잊었어요"(재설정 메일)가 있습니다.
